# Course to Notes

保留老师如何把问题讲明白的过程。默认中文、Markdown；用户指定的课程、语言、格式、范围与路径优先。不要默认写进私人知识库。

## 入口与执行

1. **未选课程**：读取 [acquisition.md](references/acquisition.md)，按目标、基础及可投入时间核实通常 3–5 门候选，比较内容、前置、难度、长度、语言、教学形式、素材可用性和不适合情形。注明评价来自大纲还是实际抽看，附官方来源，等待选择，不批量整理候选。
2. **已选课程**：核对讲师、讲次、发布页年份、实际录制年份和具体视频版本；不换课。只澄清会影响结果的歧义。建立素材清单，实际检查获取、解码、视觉和 ASR 能力，按 [acquisition.md](references/acquisition.md) 降级。
3. **整理**：读取 [editing-and-translation.md](references/editing-and-translation.md)。从字幕/音轨、画面和同版本课件形成语义单元，再选关键帧。脚本不承担语义判断。长视频保留相邻段上下文，逐讲交付。
4. **学习衔接**：读取 [learner-context.md](references/learner-context.md)，先提取各章概念与深度，再匹配用户指定范围的证据。无记录仍继续，标待确认。重点独立判断。每章标题后、正文和首图前放紧凑标记，目录同步；不删正文。
5. **成稿与续作**：按 [output-and-state.md](references/output-and-state.md) 写正文、术语和机器记录，并落实其中的可迁移交付要求。根据用户指定格式调用环境中的文档工具；Word 必须是真实 docx，需打开/渲染核对。先比较哈希与备份，再局部修订，保留手动批注。
6. **验收**：运行结构检查，实际核对内容、公式、图片与最终阅读环境；含本地依赖的交付包须从新目录中的解压副本验收。参考 [acceptance-cases.md](references/acceptance-cases.md) 选择适用行为案例。报告已处理区间、素材缺失、已核对内容和未验证分支；结构通过不证明语义正确。

## 核心不变量

- 保留动机、条件、推导、例子、反例、试错、自我纠正和有价值的就地问答；按实际讲授路径组织，不用压缩率代替覆盖检查。
- 强调性重复按实际顺序和次数保留原意表达，包括连续重复；不能以加粗或“重复三次”代替。字幕重叠由证据判断，解析层绝不去重。
- 术语键包含学科、语境与概念；不同 field 不强行统一，惯用 token、vibe coding 保留。重要纠错有来源，补充标“编者补充”，不清楚的问题不编造。
- 视觉非口述的条件、图例和必要推导也属于教学证据。固定间隔截图不能证明没有遗漏；动态过程提示需回看的区间。
- 已学、接触、明确未学、待确认相互区分；掌握说明独立且限定深度。已有文档或生成阅读稿不构成学习事件。
- 个人熟悉度与课程重点独立；未知不等于未学。学习档案仅存项目或用户指定范围，不扫描全部私人记录，不写全局记忆，不放进技能安装包。
- 不处理独立布置的作业、考试与答案；课堂实际讲解例题保留。不得自动发布、安装大模型或使用未授权收费服务。

## 确定性工具

从本技能目录运行（输入/输出使用实际路径）：

```sh
python3 scripts/parse_captions.py INPUT --output OUTPUT --source-id SOURCE_ID
python3 scripts/extract_frames.py VIDEO --times TIMES_JSON --out-dir ASSET_DIR --source-id SOURCE_ID
python3 scripts/validate_output.py LECTURE_DIR --report REPORT_JSON
```

解析器只支持 UTF-8 SRT/WebVTT。抽帧需 ffmpeg/ffprobe；记录请求时刻而非未经测量的精确帧时刻。两个产出工具拒绝覆盖已有文件。校验器检查字段、引用、覆盖与标记结构，不评估理解或知识掌握。完整数据契约、修订和格式检查见 output-and-state。

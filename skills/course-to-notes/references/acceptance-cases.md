# 行为验收与证据边界

以下是验收任务，不是已通过声明。每次实测保存输入、实际输出路径、素材类型（真实/合成）、执行者核对结论和未测边界。不要用关键词出现或规则复述代替输出评审；自动路由需要独立真实调用，作者自查不等同于路由准确率。

| ID | 给执行者的输入 | 对输出的语义检查 |
| --- | --- | --- |
| B01 | 只有主题与基础，未选课 | 核实少量候选、适配与材料，等选择、不批量处理 |
| B02 | 指定版本的一讲 | 只处理指定课与范围，核对讲次、视频版本 |
| B03 | field（物理/代数）、Fields、token、vibe coding | 场/域/菲尔兹/保留英文，按概念选词 |
| B04 | 三次明确强调相同句 | 逐次保留表达，不能仅加粗或计数 |
| B05 | WebVTT 滚动重叠 | 解析不丢证据，编辑靠音视频辨技术重复 |
| B06 | 问题不可辨，回答只有“还需要严格凸” | 不编唯一问题，标未听清 |
| B07 | 教师明确复述学生问题 | “据教师复述整理”，就地保留回答 |
| B08 | 未口述板书条件/步骤，字幕只说于是得到 | 纳入必要视觉信息并提供对应图 |
| B09 | 失败尝试、原因、修正 | 保留教学试错路径 |
| B10 | 跳过课件页、教材外部证明 | 不冒充原讲，额外证明有补充标签与来源 |
| B11 | 短公式、矩阵、板书 | 短式行内，矩阵展示，最终阅读器核对邻接与渲染 |
| B12 | 英文 Word | 实际英文 docx、图注译文、公式与图片；打开核对 |
| B13 | 仅字幕 | 明示缺视觉，非完整图文稿 |
| B14 | 独立作业与课堂例题 | 排除独立作业，保留课堂例题 |
| B15 | 本课术语更正、旧稿有批注 | 课程内更正、保留批注、报告检查范围 |
| B16 | 只做前半段 | 标实际区间与未完成范围 |
| B17 | 代入/上一讲指代 | 还原有证据的对象，链接已有结论，缺证据不补原讲 |
| B18 | 不同剪辑时长 | 时间绑定具体源 ID，不跨版本挪用 |
| B19 | 一元已学、多元未学、混合章 | 分概念/深度标记，不整章已学 |
| B20 | 只有文件、问过或生成稿 | 至多接触，不推导学习或掌握 |
| B21 | 没有记录 | unknown，完整继续，不强制测验 |
| B22 | 已学且教师强调 | 已学与重点并存，重复和正文不删 |
| B23 | 未学但只是拓展 | 不因未学自动标核心 |
| B24 | 新纠正否认旧推断、有批注 | revision、目录与章首同步，批注保留 |
| B25 | 会定义/计算但未证明 | 不外推一般定理证明 |
| B26 | 别名/跨学科同词 | 语义匹配，不按字符串 |
| B27 | 英文 Word 混合章节 | 英文章首与目录紧凑、正文完整 |
| B28 | 稿件生成成功 | 不产生学习事件 |
| B29 | 改学习目标 | 复核理由/建议，不改学习事实，标实际范围 |
| B30 | 档案更新而旧稿未更新 | 过期警告，不假称当前有效 |
| B31 | Markdown 含本地图片，用户用 Typora 阅读 | 完整 ZIP 为主要入口，明确解压后的打开路径；在新目录解压，确认图片与内部文件链接齐全，再用 Typora 核对实际显示；不能使用 Typora 时明确未验证 |
| B32 | 把正文单独复制到不含 assets 的目录 | 识别图片依赖缺失，不能因源目录或 HTML 预览正常而判定该副本可读；交付指引须说明正文和依赖一起移动，不靠生成目录的绝对路径修补可迁移包 |

自动测试：在仓库根目录运行 `python3 -m unittest discover -s tests/course-to-notes -v`（测试不包含在独立技能安装包内）。媒体依赖缺失应显示 skip 与原因，不能将 skip 计入通过。`quick_validate.py` 使用 skill-creator 提供的实际路径和可导入 PyYAML 的 Python，只检查包结构。必要时在新临时输出中执行真实请求；不改现有用户笔记进行测试。

验收至少包括一份可核对真实素材阅读稿、空档案与合成档案对比、修订保护、正常/窄阅读宽度及小型 Word 样例。无实际音频就将真实 ASR、听不清问答重建等列未验证。公式渲染、图片正确与语义正确分别报告。开发报告与课程样例留在源码/独立验收目录，不安装真实媒体和私人档案。

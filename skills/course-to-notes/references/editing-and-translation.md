# 忠实于教学过程的编辑

## 从素材到语义单元

先观察教学结构与画面变化，再结合字幕/音轨切成概念、证明、例子或问答。记录每单元起止、cue ID、画面/课件页、说话人及疑点；不机械按分钟分节。抽看不足以证明全段完整，固定间隔抽帧仅用于找变化。必要的板书前提和未口述步骤仍纳入正文。长片段重叠上下文，合并时检查术语、符号、指代、跨段证明与例子连续性。

保留动机、定义、条件、推导关键步骤、例子结果、反例、直觉、教师提醒和有价值的互动。按原教学路径组织，可合并被打断的推导，不暗换成另一套教材。不要用词数、压缩率或固定页数来判覆盖。所有处理区间按 included / omitted_noninstructional / omitted_assignment / unresolved 划分；强调性重复不能归为无信息。

## 重复与纠错

- 删除口头赘词、等待与确认无强调作用的机械重复；同句同词不构成删除理由。
- 强调要保留每次表达及顺序，包括连续重复、翻译后的重复。合成例：00:10、00:15、00:20 均说“先检查条件”，成稿仍出现三次“先检查条件”，不能只写“教师强调三次”。
- WebVTT 滚动字幕可能重叠；解析保留所有 cue，再据音视频确定是一次发声还是多次强调。未确定先保留并标待核对，不进行全局文本去重。
- 明确识别/口头错误：画面、上下文或教师自我纠正提供证据后正文采用正确版本；影响结论的改正记录位置与原因。
- 疑似实质错误：说明原讲与可能缺少的条件，不凭模型印象悄悄改成标准结论。
- 无法确定：在附近标具体缺口，不用顺畅措辞掩盖。
- 有教学价值的试错按“尝试—失败原因—修正”保留；无意口误可整理。额外证明标“编者补充”，课堂跳过则写“课堂未展开”。

## 问答与指代

有可靠姓名才用姓名。可确认同一人时用学生 A，否则“一位学生”。将问答保留在相关论证附近，不移到文末或把学生观点写成教师结论。

1. 教师明确复述：标“学生提问（据教师复述整理）”。
2. 回答与前文强烈支持一个问题：只重建最小大意，标“学生提问（根据教师回答推测）”。
3. 多种问题都可能引出回答：写“学生提问未听清”，保留可确认的回答主题。

合成反例：只有“还需要严格凸”，不能据此编造“最优解是否唯一”的提问，也不能把严格凸写成未给定目标的普遍必要条件。

“把这个代入”应还原可确认的表达式与目标式。“上一讲已证明”仅有可靠对应资料才链接；没有证据保留缺口。“这里”“向这边”依据手势与画面明确对象和方向，无法看清不猜。

## 视觉与动态过程

同版本高清课件优先；截图补板书、手写和演示。选择推导阶段图，不只保留最终整板，也不逐帧抄写。保持轴、图例、条件、相关前文；必要数学与代码重排成可复制文本。先看图再核对 OCR 的上下标、括号、转置和量词。

默认“引入—图片—紧邻解释”单栏。密集幻灯片应翻译完整相关内容，不以一行小注取代。源图通常不改写，旁边/下方给目标语言注释。动态图以阶段图和建议回看区间表达，不能承诺阅读完全替代观看。

## 术语与归属

先辨认原词所指的概念与学科，再选择标准译名。合成例：物理 field → 场；代数 field → 域；Fields Medal → 菲尔兹奖；token、vibe coding 保留。相同概念保持一致，不用同义词轮换文风；同词不同概念不强制统一。保留程序标识符、变量、逻辑量词与语气力度。疑问核对课程定义与可靠学科来源；不能确认保留原词并注明。

整门课程复用按 source_term/domain/concept/target_language 建键的 glossary。用户偏好优先，但会混淆概念时解释区别。用户纠正后核对本课相关段落、公式解释和问答，不跨课程全局替换。

本次讲授是主线。未讲课件页、教材额外证明须标外部补充与来源；冲突条件、符号或版本不能无说明拼接。除可核对短引文外，教师段落是整理后的意思表达，不用引号冒充逐字原话。

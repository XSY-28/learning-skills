# 素材与能力检查

## 选择课程

用户已选定课程时核对名称、讲师、年份/版本、讲次顺序与范围；不替换。未选时先按用户目标和基础搜索通常 3–5 门，比较预计学习结果、前置、难度、理论/实践、长度、语言、板书/幻灯片/代码/实验形式、访问与字幕/课件情况、适合与不适合之处。不要把看完等同于掌握，或只凭素材齐全/播放量决定质量。证据区分大纲与实际抽看。给真实官方链接后等用户选择。

## 获取前检查

对本讲列出视频、字幕语言/人工或自动类型、音轨、PPT/PDF、讲义、来源/署名/许可、时长与版本。不同剪辑不得共用时间轴；发布年份未必是录制年份。课件页码不自动映射分钟。

按当前环境检查，不把技能存在当作工具可用：

- 搜索与浏览器是否实际能访问该页；官方课程页和原发布者优先。
- 本地 Python 3；`ffmpeg -version`、`ffprobe -version` 及 `-h full`。调用参数使用数组，不能拼未经转义的 shell 命令。
- 若使用已有下载器，先检查路径、版本、帮助与官方文档。复用页面提供的下载和字幕入口；不用自制登录、规避限制或批量抓取方案。
- 音频识别：实际列出可调用的工具/模型、输入限制、是否需外传或收费。不因存在音频文件就宣称能听取。不自动下载大模型或新增付费服务。
- 视觉：实际打开抽帧或 PDF 页，核对小字、坐标轴、公式和图例。OCR 仅作候选。
- 格式：要求 docx/PDF 时检查对应文档工具与渲染工具；缺失时说清生成或视觉检查哪一步未完成。

同一访问错误不反复请求：尝试一个合理替代官方入口后，记录错误与缺项，继续可用分支；真实材料仍缺失时说明需补什么文件。不是要求无条件重试或改用新服务。

## 字幕优先与按需定位

默认按下面的素材路径处理，不将视频播放时长当作最低处理时长；用户指定观看方式优先。

1. **先读完整文字时间轴。** 优先取得所选版本和区间的可用字幕/转录（人工字幕优先核对，自动字幕也可作候选），保留原文、cue ID 与源时间。不为看完视频而等待播放；长字幕连续分段读取并保留相邻上下文，确认没有读取截断或遗漏中间段。只有浏览器当前显示的几行字幕不算完整字幕；解析失败不能悄悄跳过 cue。无可用字幕时，先用已有且获准的 ASR 能力转录，再按原视频时间轴核对；没有能力则进入受支持的观看分支或说明缺口。
2. **建立内容与核对索引。** 从全文列出语义单元、推导/例子/问答、强调重复和疑点，定位涉及板书、图表、代码、演示、指代及字幕空档的区间。cue 时间没有覆盖的范围仍需判断：可能静默写板书，不能自动归为无教学信息。不同剪辑、字幕偏移或识别错误先校准/记录疑点，不拿错误时间轴跳转。
3. **发现画面变化，再精查。** 对整个所选范围建立画面/同版本课件变化概览，复用工具已有的缩略图、变化候选或阶段抽帧；按内容变化而非每个 cue 重复截图。候选只是发现线索，固定间隔图或最终整板可能漏掉短暂条件、擦除和未口述步骤。对这些风险区间扩大核对、补相邻帧或连续回看；不能排除的范围保留 unresolved。随后直接 seek 到需核对的位置，打开原图/课件核对，保留推导阶段图，静态内容不重复等待播放。
4. **必要播放可倍速。** 只有字幕不可完整获取、声音需复核或动态过程不能由静态图确定时，播放对应区间；只有观看可用时连续覆盖所选范围。通过当前工具支持的播放控件选择可辨识速度（例如普通讲述先试 1.5–2 倍），确认实际速度和字幕/声音/画面能力；控件不可用不虚构成功。密集公式、问答、短暂画面或难辨声音暂停、降至正常速度或更慢回看，仍不清楚就标疑点，不继续提速。能看到视频不等于能听到音轨。倍速和跳转均沿用原视频时间，不用墙钟时间或除以倍数改写时间戳；动态阶段不能凭首尾两图补造。
5. **复用已核对素材。** 保留全文字幕索引、已核对位置、待核对区间与必要阶段图，避免在成稿/修订时从头重播或反复抽相同帧；源版本或相关内容变化时只重查受影响范围。利用既有 sources、coverage.evidence/reason 和 unresolved_items 记录实际证据，不强造调度框架或依赖新服务。

提速来自文字批量读取、直接定位和素材复用，不来自缩短教学范围。完成前按 [编辑覆盖检查](editing-and-translation.md) 对照全文与画面；保留实际未核对范围，不能宣称必然零遗漏或预设固定加速倍数。

## 分支与边界

| 可用素材 | 可以做什么 | 必须说明 |
| --- | --- | --- |
| 视频与字幕 | 先完整读字幕建立时间轴，再发现视觉变化并按需定位核对 | 字幕也可能有错；声音未复核时明确；字幕外画面仍要检查 |
| 视频无字幕 | 优先现有 ASR 再核对画面；只有观看可用时按可辨识倍速连续处理 | 未获得可用音频能力时不伪造讲述，不把可见视频当作可听声音 |
| 只有字幕 | 有时间定位的文字整理 | 缺少视觉核对，非完整图文稿 |
| 只有课件 | 按课件组织阅读材料 | 不是原讲转录，不编问答和口述推导 |
| 动态演示 | 关键阶段图和回看区间 | 静态稿不能替代运动/实验观察 |

官方人工字幕和课件是良好起点，但不是无误真值。冲突结合声音、画面、课程上下文判断；保留无法确认之处。字幕文本保留原始文件及 cue ID。WebVTT 标签/说话人提示可在编辑阶段解释，解析器原样保存，不擅自去掉信息。

使用用户提供或许可允许改编的内容，记录署名和许可。没有整篇转录/翻译授权的第三方材料采用原创学习笔记和必要短引用；私人整理不等于可公开发布。独立作业、考试和答案不下载、不整理；课堂实际例题保留。

## 工具用法与可核实来源

- `parse_captions.py INPUT --output OUTPUT --source-id SOURCE_ID`：UTF-8 SRT/WebVTT，输出 v1 cues；报错带输入行号。不支持任意 ASR JSON。合法 cue 设置不进入正文，NOTE/STYLE/REGION 块跳过，重叠与重复全部保留。
- `extract_frames.py VIDEO --times TIMES_JSON --out-dir ASSET_DIR --source-id SOURCE_ID`：times 为非空秒数数组。视频路径必须本地可读；无视频轨、缺工具、越界/非有限时刻报错。输出 PNG 与 frames.json，已有文件不覆盖。
- 对裁出的片段记录原视频区间与时间偏移；例如片段本地 10 秒对应原片 125 秒，不能忘记偏移。抽帧请求时间不是精确解码时间；用帧内容与相邻字幕确认同步。

2026-09-26 实施时核对的官方入口（今后使用时按需复查）：

- [MIT OCW 示例课程](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-1-the-geometry-of-linear-equations/)、[许可](https://ocw.mit.edu/pages/privacy-and-terms-of-use/)。该页面明确视频录于 1999 年，页面所属课程为 Spring 2010。

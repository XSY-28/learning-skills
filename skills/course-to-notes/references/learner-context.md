# 学习证据与章节重点

## 范围和证据

先提取本章学科、具体概念、别名、前置与所需深度，再在本次自述、用户提供/指定的学习材料或当前上下文已有且可溯源的记录中匹配。禁止默认遍历全部文件、私人笔记或聊天。用户已给清单不重复询问；无记录可一次简短询问可用清单/位置，同时继续整理，允许空档案，不强制测验。

`learner-profile.json` 存在输出项目或用户指定可复用档案；不写全局记忆、原始笔记或技能安装目录。只存必要摘记和来源范围。每项记录含来源、可用日期（未知 null）、学科、概念、深度、声明、来源类型。新材料交付绝不产生 studied 事件。

## 四种状态与独立掌握说明

| learning_status | 标签 | 判断条件 |
| --- | --- | --- |
| studied | 已学过 | 明确自述或可靠记录证明有实际学习活动，仅限所支持概念与深度 |
| exposure_only | 有接触记录 | 问过、持有材料或有助手生成讲义，尚不能证明学习活动 |
| explicitly_unlearned | 明确未学 | 当前明确自述未学，或确认进度未开始且无相反新证据 |
| unknown | 待确认 | 无足够记录、不能读取或证据冲突尚未解决 |

`mastery_basis` 独立使用 not_assessed / self_reported / performance_supported。后两者分别需要用户自评或可核对表现，注明支持的能力深度；一个基础例题不能支持整章证明或进阶推广。studied 不推导掌握，旧学习事件不证明当前仍熟练，也不因时间久改判未学。

按语义匹配别名、学科与深度，不按词频/标题/字符串匹配。导数定义、一元计算、多元梯度几何、一般定理证明分开。不同词可能同概念，如“方向导数”与 directional derivative；同一个 field 在物理和代数不是同概念。保存 evidence_ids 与匹配理由；不虚构置信度。

混合章写“已学：……；新增于已知记录、是否学过待确认：……”。只有明确未学证据才直接说未学；记录不完整时不把未知称为用户全新。仅助手生成稿至多 exposure_only；未实际提供记录时可 unknown。

## 独立评定重点与阅读建议

课程重要性 key / regular / undetermined（重点/常规/待判断）。理由来源 teacher_emphasis / course_dependency / learning_goal / editorial_assessment，附具体证据。教师强调与编者判断不可混称；只用已核对依赖，不编造后续课程关系；篇幅或公式数量不决定重点。常规不等于无用。

个人建议 read_carefully / targeted_review / quick_review / undetermined，分别优先细读/针对性复习/快速复习/待确认，给具体原因。没有目标或基础时仍可据课程证据标重点，个人建议待确认。已学仍可能重点；未学的拓展示例不自动变核心。建议不替代正文、不默认折叠或删减已学部分，也不删除强调性重复。

章标题后、正文及首图前通常三行（2–4 行）：

> **学习衔接：** 已学过一元导数定义与基本求导；明确未学多元梯度（合成自述 e1、e2）。
> **章节重点：** 重点——本段方向解释是后续已核对更新式的前提（课程依赖）。
> **阅读建议：** 优先细读梯度几何，求导回顾快速复习。

以上是合成例，不是当前用户真实基础。英文输出使用 Learning connection / Course importance / Reading advice；其他格式保留同样结构，目录同步简短标记，不依赖颜色、悬浮或插件。

## 纠正和目标变化

1. 读取现有哈希，保留手动更改与修订前版本。范围限定本课程/已指定共同档案。
2. 追加最新用户纠正作为证据，旧证据保留历史，可加 supersedes 指向旧 ID。当前明确纠正优先于旧推断；未解决矛盾标待确认。
3. revision 加一，逐个复核受影响概念、重要性理由和阅读建议；更新 annotations 的 profile_revision、章首与目录。记录实际检查和未检查的讲次。
4. 改目标时更新 learning_goal 及相关目标理由，不修改过去学习事实。只更新标记和必要相关正文，保护原始记录及用户批注。
5. revision 不一致由校验器警告；它不自行决定新的学习结论。档案 revision 的递增不能被当作已经完成所有讲次同步。
